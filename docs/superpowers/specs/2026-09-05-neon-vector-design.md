# Neon Vector design
An original five-world arcade chase-camera spaceflight game, built with Three.js, TypeScript and Vite. Fully local procedural assets and Web Audio; no runtime asset downloads. Desktop keyboard and mouse controls. The campaign comprises 70–95 second routes with increasing speed, themed obstacles, risk/reward boost chains, combat encounters and scripted finales. Mission completion unlocks the next route and saves score, rank and time independently. A finite world-relative simulation moves objects toward the ship, allowing bounded pools and stable collision coordinates. Camera lags the player and widens under boost. All scoring and damage rules live in pure domain functions. UI overlays provide mission selection, HUD, pause, debrief and instant retry. Generated geometry supplies original ship, enemies, obstacles, planets, stations and effects. Safe routes always remain navigable. Combat finales have destroyable objectives; escape finales require survival. Deterministic route generation enables repeatable learning and automated checks.
